疾风剑客 · 夏日海风

这是可直接上传的完整编辑器主题包。蓝天、海岛和碧海作为主视觉，剑客背身临海，披风迎风展开，回望镜头；按钮采用紧凑的海蓝风纹与单片羽叶，透明 PNG 中以清晰文字为主。

使用方法
1. 更新到支持「图片控件」的版本。
2. 在控制面板／域管理 → 编辑器主题，上传整个 ZIP，不需要先解压。
3. 选择关联徽章，预览并发布。持有有效徽章的学员即可在编辑区选择此主题；失效时自动回到基础主题。
4. 图片和其他主题素材上传到平台对象存储。

包内内容
- background.jpg：夏日海岛剑客背景。
- run.png、submit.png、pretest.png、records.png、theme.png：透明 PNG 主控件，文字已在图中。
- 其他 PNG：输入输出标题、评测表头、语言入口、退出、题目入口、设置入口和空白提示。
- theme.json：全部 21 处控件的素材映射和显示尺寸。
- preview.jpg：由实际编辑器截取的完整装配界面。

自行制作
直接替换对应 PNG 即可改图。PNG 的透明区域会保持透明，按钮不会再强加方形底框。推荐按显示尺寸的 3 倍制作，正文文字要足够大，边缘留少量空间以免光效被裁切。

配置示例：
"controls": {
  "run": { "asset": "run.png", "width": 118, "height": 40 },
  "pretestTitle": { "asset": "pretest.png", "width": 64, "height": 36 }
}

可选的 hover、active 字段可分别指定悬停、按下／选中状态图片。未指定时，系统提供轻微亮度反馈。尺寸范围为宽 16–320、高 16–120 像素；小屏幕自动适配。各入口均保留原有功能、键盘操作和文字名称，图片不可用时恢复默认显示。

语言入口图片为装饰底图，不要在图中写死 C++ 或 Python。代码、当前语言、真实评测结果、运行状态和倒计时始终保持实际文字。不要把整个界面截图当作背景上传；preview.jpg 是单独预览，不会进入代码区。

可定制区域
run 运行自测；submit 递交评测；pretestTab 自测入口；recordsTab 评测记录入口；pretestTitle 自测标题；recordsTitle 评测记录标题；inputTitle 输入标题；outputTitle 输出标题；theme 主题入口；language 语言外壳；close 退出；problemTab 题目入口；settingsTab 设置入口；recordStatus 评测结果表头；recordMemory 内存表头；recordTime 用时表头；recordDate 提交时间表头；emptyRecords 无记录提示；emptyRecordsHint 无记录说明；emptyOutput 无输出提示；inputPlaceholder 输入提示。

制作记录
背景和五张核心控件使用内置图像生成工具，参考老师提供的疾风剑客勋章设计；辅助标题及小型图标为专门绘制并栅格化的界面素材，使用清晰中文排字。未使用 CLI 图像 API。

阅读与交互
代码区域有独立的阅读底色：浅色主题至少94%、深色至少92%遮盖，平台对真实代码色、行号和选中区域作对比度保护；输入输出采用纯色底，避免插画影响阅读。
悬停／键盘聚焦有明显底部强调、柔和底色与轻微上移，选中状态保留独立标记。控件仍支持自行上传悬停和选中PNG。
缩窄工具栏时会按可用空间折行，不遮挡、不裁掉按钮。
