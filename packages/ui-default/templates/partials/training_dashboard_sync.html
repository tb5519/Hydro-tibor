uid 使用上方学员列表中的学员编号，domainId 使用授权课堂的括号内编号。开始时间必须带时区；durationHours 是实际小时数，支持小数，须大于 0 且不超过 24，只接收已经结束的课程。

externalId 是本工作区内唯一的学员课程记录编号，建议包含来源平台、课程编号和学员编号。同一节课有多名学员时，每名学员需使用各自的记录编号。同一编号、同一内容重复推送不会重复累计；同一编号内容改变会返回冲突。更换 Token 后也无需更换记录编号。

建议通过 Authorization 请求头携带 Token，也可以放在 JSON 的 token 字段中；不要放在 URL 中。Token 只能向授权课堂同步，调用时仍会检查教师权限和学员归属。
