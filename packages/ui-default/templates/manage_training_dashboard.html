{{ icon('info') }}计时与统计说明{{ icon('chevron') }}

学习总时长 = 自主训练 + 上课时间。同一学员的重叠课程只计一次；上课期间发生的站内训练归入上课时间，只将课外部分计入自主训练。跨日课程按北京时间分别计入各天。

站内训练是学习投入的估算：读题、编程、自测、查看评测结果和每日一练中的活跃时间会被记录；无操作超过 5 分钟后暂停，重新操作后继续。切到后台或同时打开多个页面不会重复累计。时长不代表学习质量，请结合题目、提交和课堂观察了解孩子的情况。

通过题目统计所选时间内每位学员通过的不同题目，并非历史首次通过数。最近活跃按所选范围内的计时、上课或提交记录显示。训练计时从功能上线后开始，过去的训练无法补算；“暂无记录”不代表没有学习。历史日汇总没有精确时间段，无法判断是否与补录课程重叠；新训练记录会自动去重。周均时长按有完整计时覆盖的最近 4 个完整自然周计算。

这些学习数据仅向有权限的教师展示，不向学员本人或其他学员开放。
