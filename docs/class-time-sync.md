# 上课数据与训练看板同步

教师在「学员训练数据看板 → 上课数据同步」选择允许同步的课堂，生成接口地址和 Token。完整 Token 只在生成成功后显示一次，请交给上课平台的后端保存。每位教师在每个工作区只有一个有效 Token，有效期一年；重新生成后旧 Token 失效，停用后停止接收新数据，已同步记录保留。

## 请求

使用页面生成的完整接口地址，以 JSON POST 推送一名学员的一次已完成课程。不同学员分别推送。示例中的域、UID 和 Token 均需替换为实际值：

```http
POST /d/python/training-time/classes
Authorization: Bearer <TOKEN>
Content-Type: application/json

{
  "externalId": "classflow-lesson-123-student-101",
  "domainId": "python",
  "uid": 101,
  "startAt": "2026-10-27T10:00:00+08:00",
  "durationHours": 1.5,
  "title": "Python 循环课堂"
}
```

| 字段 | 规则 |
| --- | --- |
| `externalId` | 本工作区唯一且稳定的学员课程记录编号，最长 128 字符。建议包含来源平台、课程 ID、学员 ID。同一节多人课的每位学员必须使用不同编号。 |
| `domainId` | 本站课堂编号，必须在 Token 授权范围内。页面生成 Token 的课堂选择中可查看。 |
| `uid` | 本站学员整数编号，可在看板学员列表中查看。上课平台需保存外部学员与本站 UID 的对应关系。 |
| `startAt` | 含时区的 ISO 8601 开始时间，例如 `2026-10-27T10:00:00+08:00`。 |
| `durationHours` | 实际小时数，JSON 数字，大于 0 且不超过 24，支持 `1.5` 等小数。结束时间由开始时间加课时计算，课程必须已经结束。 |
| `title` | 可选，最长 200 字符，作为看板课程名称展示。 |

也可把 Token 放入 JSON 的 `token` 字段。请求头和请求体同时提供时必须一致。URL 查询参数不接受 Token。请由上课平台后端调用并保管 Token。

## 幂等与返回结果

第一次接收返回 HTTP 200：

```json
{
  "accepted": true,
  "duplicate": false,
  "externalId": "classflow-lesson-123-student-101",
  "domainId": "python",
  "uid": 101,
  "startAt": "2026-10-27T02:00:00.000Z",
  "endAt": "2026-10-27T03:30:00.000Z",
  "durationHours": 1.5
}
```

相同编号和内容重试时返回 `duplicate: true`，不会重复插入或增加时间。更换 Token 后仍使用原编号。同一编号对应不同学员、课堂、时间、课时或标题时返回 HTTP 409；当前接口不提供修改或删除已有记录的操作。其他错误返回 JSON `error`、`message`：格式错误为 400，Token 无效、过期或停用为 401，教师权限、工作区或学员归属不符为 403；超出调用频率为 429。

Token 只能写入所授权课堂的有效学员课时，不能登录教师账号或读取学员数据。每次调用都重新核实教师权限、工作区状态、课堂和学员归属。服务端只保存 Token 的 SHA-256 摘要。

## 统计口径

- **上课时长**：同一学员各课程时间段的并集，重复或重叠课程只计一次。
- **自主训练**：有效站内训练中处于上课时间段以外的部分。跨所选课堂的上课与训练也会核对重叠。
- **学习总时长**：自主训练加上课时长。例如训练 10:00—11:30、上课 10:30—12:00，结果是自主训练 30 分钟、上课 90 分钟、学习总时长 120 分钟。
- 所有日统计按北京时间拆分。选择日期范围时，跨边界课程只计范围内部分。课堂筛选仅包含所选课堂的记录；提交和通过题目继续沿用原有统计口径。
- 课堂之间也有重叠时，总量只计一次；重叠部分按课堂编号的固定顺序归属到一个课堂，保证各课堂分布之和等于总量。
- 学员详情列出原始课程，单条显示范围内时长。原始课程之间如有重叠，单条时长相加可能大于合并后的上课时长。

### 历史数据限制

升级前训练只有日汇总，没有实际时间段，无法准确还原与补录课程的重叠。这些历史训练保持原值，看板提示存在不能精确去重的历史部分；不根据首次、末次活跃时间猜测扣除。升级后的新训练心跳保存精确区间，补录课程后会自动重新计算重叠。极端情况下当日精确区间数量达到存储上限，额外训练也保留为日汇总并使用同一提示。
