# Scratch 题目 ID

Scratch 创作题和知识练习共享展示 ID（`problemCode`）。老师在新建或编辑页设置「题目 ID」；新建留空自动分配 `S1`、`S2` 等，编辑留空保留原编号。旧题按稳定创建顺序补号并持久保存。

题库先合并两类题，按 ID 自然升序排序，例如 `S1`、`S2`、`S10`，再搜索、筛选和分页。搜索包含 ID、名称和标签。

ID 最多 32 字符，去首尾空格并转大写。允许不以 0 开头的正整数，或以字母开头，包含字母、数字、短横线和下划线的编号。同域两类题共用唯一编号空间；隐藏题也占号。

展示 ID 独立存储在 `scratch.problem.code`，自动计数器在 `scratch.problem.counter`。ObjectId、docId/pid、路由、作品和答题记录不随改号改变。人工指定的大编号不会推进自动计数器。

保存采用唯一索引、同题预留锁和 revision CAS。改号期间旧、新编号同时保留；保存失败回滚，过期预留可回收并隔离迟到的提交。新建知识练习的文件和编号保存成功后才公开。

UI 必须在开发环境构建，并随 Git 提交预构建资源；服务器仅拉取准备好的提交并重启服务。
