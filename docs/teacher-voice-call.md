# 老师助手语音通话

老师打开「老师助手 → 语音通话」，选择在线学员并拨号。学员在页面内收到来电，点击「接听」后双方开始通话。双方均可静音或挂断。

## 使用与交互

- 通话使用页面内浮条，不额外弹出通话窗口。浮条在共享期间也能操作。
- 共享与语音各自管理连接：开始或结束共享不挂断语音，挂断语音也不结束共享。
- 语音、聊天和共享连接由常驻外层页面持有。站内切换题目、课堂、作业、IDE 和个人中心时，只更换内容页面，麦克风与通话连接保持原有实例；不需要重新接听。
- 手动刷新整个浏览器标签、关闭页面、网络中断或服务器重启仍可能中断连接。同一标签重新载入后按服务端确认的通话状态恢复；若浏览器阻止自动播放，需要点击恢复声音。退出登录或切换账号会立即结束旧账号的本地通信实例。
- 首次拨号、接听需要允许麦克风。来电本身不会开启学员麦克风。
- 麦克风需要 HTTPS；本机开发可使用 localhost。普通局域网 HTTP 地址不能直接用于麦克风测试。
- 一个用户同时只有一通电话，同账户其他标签页不能自动加入正在进行的音频。
- 45 秒未接听结束呼叫；断线保留约 20 秒重连机会，超时结束。

## 传输和资源

音频通过同源加密 WebSocket 双向中转，服务端只转发音频帧，不录音、不将音频写入数据库。浏览器通过 AudioWorklet 采集与播放，启用设备支持的回声消除、降噪和自动增益。

传输为 16 kHz 单声道 μ-law，每帧 40 毫秒、640 字节，每秒 25 帧。加入 Base64、控制字段和协议开销后，每个方向约 25–28 KB/s；一对师生双向传输时，服务器入口、出口各约 50–56 KB/s（每小时各约 180–202 MB，具体取决于协议开销和静音情况）。没有第三方按分钟收费，消耗现有服务器带宽。服务器不进行转码。

发送、转发与播放队列均有上限，过期音频丢弃而非无限排队。网络拥塞仍可能导致断续或断线；这是实时通信需要考虑的正常失败路径，界面应显示重连或结束状态。

## 权限和持久化

语音沿用教师与学员的课堂、工作区权限，要求登录有效且禁止代登录使用。拨号和接听重新检查双方权限；活动通话周期性复查权限和连接，挂断立即停止后续转发。

数据库仅保存在线信息、参与者、通话状态和短期过期时间；唯一参与者索引避免并发拨号产生多通电话。音频仅通过进程内事件或临时进程通信中转，不进入持久事件队列。

## 发布

本地构建界面后提交 manifest 和对应静态文件；服务器执行 `docker/deploy-prebuilt.sh` 拉取已准备好的提交，等待 Hydro 就绪后再重启 Judge。服务器不构建界面或镜像。
