# 课堂共享模式

老师打开悬浮助手，点「共享模式」，选择在线学员即可连接。没有观看、编辑、控制三个开关：不操作就是观看，直接操作即可协助。学员端在页面底部显示「老师正在协助」，不遮挡顶部菜单，提示本身不拦截点击。老师通过助手切换学员或断开。

## 当前支持范围

- 学员有权访问的站内页面，包括比赛详情和子页面、个人主页、个人中心、我的课堂、Python / C++ 学习页和 Scratch 页面。
- 学员与老师共同修改 Monaco 或代码文本框；远端修改触发学员端原有草稿保存流程。
- 同一浏览器内跟随学员当前平台标签页，包括新打开的平台标签页；不会跟随同账号的另一台设备。
- 允许进入题目、切换学习页、打开在线编程、切换语言、运行测试及查看相关面板；学习页的菜单、标签、筛选、记录弹层和选择题选项也通过学员端原有控件执行。选项变更触发原有页面事件，题目切换后旧选项指令失效。
- 老师在共享页面上拖选题面等普通文字，双方立即看到完整的不规则外轮廓和宽胖箭头。行内代码、公式及相邻行合并为一个块，段落间直接连接，不绘制内部边线，短行仍保留自己的长度。箭头选择选区外有空间的一侧；没有安全空位时仅保留轮廓，不覆盖重点。未写批注的临时重点在老师点击别处时自动消失，没有关闭按钮。
- 正文与代码选区统一按 **Shift＋回车** 打开批注，双方同时看到气泡，老师可直接输入。独立箭头改为气泡与重点之间的连接线；文字和中文输入过程实时同步，气泡里的普通回车用于换行。气泡只显示内容，不显示标题或底部提示，默认按文字所需空间自动伸缩，删字后收紧，单字可缩成小气泡。拖动位置不会固定气泡尺寸；只有主动调整大小才保留手动尺寸。缩放后的老师视图也按学员的页面尺寸同步。
- 写有文字的批注可同时保留多处，点击其他地方或选择新重点不会移除它们；点击气泡边缘的小 **×**，或清空文字后点击别处，才移除该处。删除和调整大小控件在老师鼠标移入或编辑时显示，不占正文空间；学员不显示这些控件。空白气泡在离开后自动消失。
- 批注输入、学员显示和尺寸测量使用同一套独立字体，不受个人页面字体或代码字体设置影响；测量保留小数宽度并预留 1px 余量，字体就绪后重新测量。长文字仍可滚动，但不显示会挤占正文宽度的系统滚动条。顶部淡紫拖动条高 18px，向上延伸，不覆盖正文；学员看到同样外观，只有老师可以拖动。
- 老师在代码编辑区选择代码时，双方同样看到选区框和箭头；普通回车执行编辑器原有换行，Shift＋回车打开批注。代码批注可以同时保留多处，跟随代码的插入、滚动和布局变化；批注使用独立同步文档，不写入代码、草稿或代码撤销历史。只读代码也可以标注。取消代码选择时仅移除临时提示。
- 老师可以拖动在线编程页面的左右、上下分隔条，调整题面、代码和测试结果区域，双方同步使用学员页面的布局约束。
- 正式提交、保存作品、删除、账号设置、付款等操作仍由学员自己完成。浏览器文件选择框、摄像头权限等系统弹窗不在共享范围。
- Scratch 的积木区支持老师远程点击、滚动、拖放积木和修改字段，代码／造型标签、绿旗和停止也可操作。运行结果同步学员实际舞台画面；它保留原来的隔离 iframe，老师端只重放经过清理的页面与图片，不另外运行一份学员脚本。保存作品、导入／导出和新建作品仍由学员操作。
- 老师按住鼠标右键拖动即可画临时笔迹，紫色柔和线条带浅色描边，松手后停留 5 秒，再用 1 秒淡出。老师自己的页面可直接使用；共享时学员同步看到，正文、代码区及 Scratch 页面均支持，其他学员不受影响。
- 最近一条临时笔迹还可见时按 **Shift＋回车**，立即打开标签并聚焦输入，同时固定笔迹。标签文字实时同步，普通回车换行，顶部拖动条可移动标签，小 **×** 删除标签和对应笔迹。固定后不再自动淡出，可以同时保留多条；没有待固定笔迹时，Shift＋回车仍按原规则打开正文或代码选区批注。标签内按键不触发新标签，中文组词不误触发快捷键。以上均在当前页面／共享会话内保留，换页、断开或切换学员后清除。
- 图表 Canvas 以有流量和尺寸上限的画面更新同步。浏览器系统窗口、外部网站的嵌入内容、密码、登录验证及令牌不在显示范围内。

老师原页面保留在内存中，连接期间不跳转网址、不更换账号；断开后恢复原代码草稿、滚动和焦点。若老师主动刷新浏览器，原网页仍遵循它本身的刷新/草稿恢复逻辑；共享目标可自动重连。尚未确认同步的老师修改会保留到当前标签页的 sessionStorage，并显示下载副本入口。

## 同步与权限

使用同源 WebSocket `/live-share/conn`，沿用登录态和课堂/工作区权限。页面成功授权后才签发短期共享凭证。一个老师和一个学员各自只能占用一个活动房间；消息绑定房间、学员标签页和页面版本。换页后旧点击不重放，控件指纹防止旧节点指向新的按钮。

页面由 rrweb 采集结构变化，老师侧在禁止脚本执行的 iframe 重放；代码使用 Yjs 合并并发修改，通过独立编辑器覆盖镜像内原编辑区域。老师的原编辑器不复用，也不写入学员模型。

共享期间将代码换行统一为 LF，避免 Windows 与其他系统的换行长度不同导致并发编辑错位；中文输入法组词期间暂存远端更新，提交组词后再合并。页面异步更新会丢弃过期结果，防止旧草稿覆盖刚同步的代码。同一个代码模型只建立一次协作绑定。

老师侧编辑区域跟随学员的字号、行高、自动换行、缩进、行号、缩略图与配色，断开时恢复老师原主题。页面和代码区域均支持双向滚动；老师连续滚动时持续发送目标位置，避免等滚轮停下才同步，也避免旧位置回传造成跳动。

不同分辨率下默认等比例适合老师窗口：老师屏幕较大时自动放大，较小时完整缩小，学员的页面布局和编辑器尺寸保持原样。左下角提供缩小、当前比例、放大与「适合窗口」；点当前比例恢复 100% 并回到画面左上角，方便直接阅读代码行首，也可按 Ctrl / Command 滚轮围绕鼠标位置缩放。放大后通过滚动条或按住空格拖动画面查看边缘；编辑代码时的空格仍正常输入。缩放和移动查看只改变老师侧视图，不滚动或缩放学员页面。普通滚轮仍同步操作学员页面。

代码输入框同步学员的换行、内边距及字体布局。代码重点与批注的轮廓以学员端实际测量的行边界为准，老师端按同一组页面坐标缩放显示；几何数据仅在变化时合并发送。收到新边界前保留即时本地反馈，旧页面、旧代码、旧滚动位置或旧尺寸的边界不会覆盖当前选区。

重点标注绑定当前共享页面的文字节点和原文范围，代码批注使用 Yjs 相对位置绑定代码选区。滚动、缩放及页面排版变化后按内容的新位置绘制，不使用老师屏幕的绝对坐标。每页最多保留 50 处正文重点，每个代码编辑器最多保留 40 处批注，每条批注最多 1000 字，长批注可在气泡内滚动阅读。批注只是本次共享的临时提示，不修改题目、答案或学员的文字选择；切换页面、学员或结束连接会清除。私密内容和普通表单不参与重点标注。

Canvas 和 Scratch 舞台画面以有上限的频率更新，优先保证学习页面与代码同步，不是高帧率屏幕视频。站内音视频按播放位置跟随；老师侧静音，避免双方已有通话时重复播放声音。

Scratch 控制指令同时绑定共享会话、父页面、受控 iframe 和当前桥接租约。每次点击重新核对目标身份及真实命中位置，滚轮以稳定滚动容器为目标，断开后停止控制并使旧 iframe 指令失效。浏览器系统窗口和任意外部 iframe 不接受这些指令。

画笔按学员页面的 CSS 坐标同步，老师的显示缩放和设备像素比不改变路径。每批最多 32 个点、每条最多 2048 个点、最多保留 32 条；已固定的笔迹不会因画新笔迹被淘汰。标签仅传递纯文本、位置和尺寸，最多 1000 字，使用老师测量后的同一尺寸显示。数据只在当前连接内转发，不保存到作业或数据库。重放页面重建时重新绑定监听，避免翻页后不能画画。

失去连接时停止远程操作；恢复后先获得完整页面与编辑器状态，再继续操作。未确认的代码更新使用 CRDT 重试，不重复执行点击。双方各自撤销自己的修改。若共享期间代码发生改变，结束时保留学员代码和视图，重新建立本地普通撤销历史，避免旧撤销记录误删协作后的内容。

连接状态和短期房间元数据保存在 MongoDB。页面与代码数据不写入 MongoDB 通用事件队列，通过当前进程或同一 PM2 集群转发。跨独立服务器实例暂不支持。登录状态和权限持续复核；退出登录或移出授权范围会结束共享。

## 资源与部署

普通学习页只加载连接控制代码；教师额外按需加载独立的轻量画笔模块，页面采集、重放和协作编辑模块仅在连接双方按需加载。代码更新按 40ms 合批，光标最多每 50ms 发送；老师页面滚动、Scratch 拖动／滚轮和画笔按 32ms、代码区域滚动按 40ms 合并发送。以上是发送间隔，实际到达时间还受网络影响。页面快照分块传输，服务端设有包大小、频率和积压上限。超过支持范围的超大页面或代码会显示暂停提示，学员原页面仍可继续使用。

本地浏览器依赖固定在 `build/live-share/package-lock.json`。更新依赖时在本地运行：

```sh
cd build/live-share
npm ci --ignore-scripts
node build.mjs
cd ../..
yarn build:ui:production
```

生产 UI 本地构建会同时调用 `build/scratch/build-live-share-frame.mjs`，更新 Scratch 的共享采集脚本、HTML 引用、对应源码包和校验清单。新脚本使用内容哈希文件名及一年缓存，HTML 更新会加载新版本。

提交 vendor、许可证、UI manifest 和所有引用的 hashed chunks，以及 Scratch 预构建变更后推送。部署脚本只允许经过校验的预构建产物；服务器不安装这份构建工具、不构建 UI、不构建 Docker 镜像。服务器拉取提交后先重启 Hydro，等待健康，再重启 Judge。
