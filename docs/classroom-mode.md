# 上课模式与预约

## 老师与学员

老师打开「助手 → 上课模式」，选择当前课堂中的一名学员。

- **立即上课**：点击「邀请并开始上课」，老师进入课堂。学员收到页面中央的邀请，点击「点击上课」后加入。离线学员上线后可查看尚未结束的邀请。
- **预约上课**：填写北京时间、课程名称和计划时长。首页周赛右侧显示课程卡；没有周赛时显示在首页内容区。预约到时，学员看到居中提醒，可以点击加入或稍后提醒。
- **分享／共享**：默认分享老师的页面。老师可以切换到共享学员页面，再切回分享。沿用已有教学连接及批注，摄像头、麦克风不随切换重新开启。
- **退出与结束**：学员离开只退出自己的课堂连接；老师可以暂时离开，也可以结束整节课。结束后停止设备采集并关闭桌面悬浮窗。
- **历史课程**：老师在上课面板下方查看历史课程。超过预约时间但尚未下课的课程保留管理入口，可以直接结束；结束另一节旧课不会中断当前正在上的课。

历史列表覆盖原授课老师仍有管理权限的课堂，并按原课堂地址执行操作。未结束的历史课程不按条数截断，已结束／取消的课程显示最近 100 条。学员移出课堂后，原老师仍可在自己的授权范围内结束旧课；关闭旧课后，学员的旧提醒在列表刷新时移除。

老师和学员主动离开课堂、老师结束当前课堂或历史课程，都需要先确认；取消后不发送退出请求、不关闭设备。注销登录、切换账号，以及会注销当前登录的安全设置，也在请求发送前确认。刷新、关闭页面和离开平台使用浏览器的离开页面提示；浏览器决定其文案及是否允许显示。平台内保持课堂连接的正常页面切换不需要退出确认。

邀请、预约和提醒到达时，设备保持原状态。学员点击进入课堂时，支持整屏共享的浏览器先让学员选择屏幕。选择或取消后，课堂按本节课的设备设置分别开启麦克风和摄像头。浏览器需要授权时，页面提示如何允许相应设备。学员可以在摄像头关闭或麦克风静音时继续上课，之后单独重试。页面需要 HTTPS，本地开发可用 localhost。

登录后的平台常驻连接单独接收课程变化通知，不依赖学员已经进入课堂。老师立即上课后，学员在其他平台页面也会同步原课堂的邀请；通知重连时重新读取当前授权邀请，避免断线期间遗漏或继续显示已经结束的课程。收到通知仍须由学员点击上课，不会自动开启设备。

## 桌面悬浮

支持 Document Picture-in-Picture 的桌面浏览器可以把相机和课堂按钮放在其他应用上方，窗口可拖动和缩放。老师点击开始或加入时预先打开窗口，入课成功后显示课堂。学员入课时如果已打开整屏选择器，可以在课堂页面点击「打开悬浮窗」。浏览器拦截或用户关闭桌面窗口后，可从课堂页面再次打开。

默认向浏览器申请 220 × 350 像素的窗口，浏览器决定实际尺寸。相机占满画面区宽度，窄窗中老师在上、学员在下；双摄在宽横窗中并排显示。只有一路开启时，另一方收成一行，保留姓名、状态及可用按钮。网页内浮窗按可用屏幕宽度显示，矮屏可以滚动查看内容，底部保留退出按钮。

本人画面内有摄像头和麦克风按钮。老师可点美颜按钮，在两幅画面之间调整效果；支持调整窗口尺寸时，展开后窗口增高，收起后恢复。底部的「结束上课」或「离开课堂」会弹出确认框，选择「继续上课」可返回原画面。

没有 Document PiP 时，课堂尝试标准视频画中画或 Safari 视频画中画。此类窗口显示当前可用的一路或两路画面，摄像头、静音和下课等按钮在原网页中。完全不支持画中画的浏览器使用页面浮窗。结束课堂或关闭网页时同步关闭画中画。

## 查看学员整个屏幕

学员可在入课时选中「整个屏幕」并点击浏览器的「共享」，为本节课准备桌面采集。老师点击学员画面上的屏幕按钮后，课堂才开始向老师发送屏幕画面。学员在入课时取消、选错窗口或未完成授权，仍可继续上课，之后可以在课堂中点击「选择整个屏幕」重试。浏览器要求从主页面授权时，点击「回页面授权」继续。课堂只接受浏览器标识为整块显示器的采集源。

桌面按完整比例显示，不裁切、不镜像；最大 1280 × 720、目标 8 帧，与摄像头和语音独立限速。老师切回摄像头后暂停桌面编码和发送，保留学员本次已明确授权的采集流，方便再次切换。学员随时可以点画面内的停止共享图标；结束课堂或离开时关闭屏幕采集轨道。

双方使用新版页面时，老师端只在查看已授权的屏幕期间请求新画面。网络稳定后逐步恢复桌面细节，拥堵时优先减少桌面帧的大小和频率，给同一连接中的语音、摄像头留出时间。老师端在解码完成后再确认帧的有效期；切回摄像头、断线或停止共享都会清除上一轮桌面预览。

屏幕请求、授权状态和帧均只存在于当前媒体连接，不写入数据库。短暂断线暂停传输并清掉旧画面；连接恢复后重新确认观看意愿和已有共享状态，不自动弹出新的屏幕采集授权。新页面或旧采集已停止时，仍需学员再次点击浏览器授权。

浏览器要求用户主动点击才能打开画中画，无法由预约计时器代为弹出桌面窗口。整页刷新后会自动恢复课堂；若浏览器要求重新点击才能播放声音或打开画中画，会保留课堂连接并显示恢复入口。

## 老师和学员使用 Mac 上课

首次入课时，学员在系统选择器中选「整个屏幕」，老师就能在本节课内随时切换查看。选择「取消」也能进入课堂。若 Safari 无法确认所选内容是整个屏幕，页面会说明原因，摄像头和语音可继续使用。

Safari 的相机与麦克风权限在「Safari 浏览器 → 设置 → 网站」中分别设置。使用 Chrome 时，可从网址左侧的网站设置查看。浏览器已经允许但仍提示权限不足时，打开苹果菜单中的「系统设置 → 隐私与安全」，按设备检查「相机」「麦克风」或「录屏与系统录音」。旧版本 macOS 的录屏设置可能显示为「屏幕录制」。[Apple 的 Safari 网站设置说明](https://support.apple.com/zh-hans/guide/safari/ibrwe2159f50/mac) · [Apple 的 Mac 录屏权限说明](https://support.apple.com/zh-cn/guide/mac-help/mchld6aa7d23/mac)

Safari 的系统画中画显示视频，静音、共享和离开课堂的按钮保留在原网页。合盖期间课堂的实时采集和传输会暂停；开盖、解锁或切回课堂后会检查原有连接，恢复仍在进行的课。若 Safari 暂停了声音，可点「点一下，听课堂声音」。

在在线 IDE、题目代码和共享代码中，鼠标放在代码上，按住 ⌘ 滚动鼠标或双指滚动触控板，即可调整字号。光标在代码区内时也可以按 ⌘ 加号或 ⌘ 减号。

## 摄像头与语音传输

课堂通过同源 WebSocket 转发实时 JPEG 画面和 16 kHz 单声道 μ-law 语音。浏览器向摄像头请求 960 × 540、每秒 25 帧。摄像头实际能力、画面复杂度和网络状况决定对方看到的分辨率与帧率。

新版接收端定期告知发送端当前能接收的画质和已收到的最高帧号。每次请求只在短时间内有效。发送端按请求调整 JPEG 大小和频率，网络稳定时逐步提至 960 × 540、每秒 25 帧，拥堵时可降至 320 × 180、每秒 5 帧。未确认的画面过多时，只发送少量小画面探测恢复情况。接收端在解码前后复核时效，电脑唤醒、断网重连后丢弃已过期的画面。语音有独立的传输额度，网络拥堵时优先舍弃摄像头画面。

同一节课中有旧版本页面时，仍可按原有 JPEG 格式收发摄像头画面。服务器继续限制每路视频最高 3 MiB/秒，单帧不超过 262,144 字符。摄像头画面只转发至本节课对方当前的设备连接。

摄像头和音频只实时转发，不录制、不写入数据库或持久事件队列。传输限制帧大小、帧率、时间、队列和拥塞积压，丢弃陈旧画面。服务器保存课程安排、参与者和短期设备连接租约。

## 老师美颜

老师摄像头提供美白、磨皮、亮眼三个 0～100 调节项，默认轻度处理。点击画面内美颜按钮展开画面外的折叠调节区，参数按老师账号保存在本机，设为 0 可关闭相应效果。学生自己的摄像头保持原画。

亮眼在本机低分辨率、低频率定位双眼，仅对可靠眼区中的眼白适度提亮；闭眼或未能可靠定位时不应用该效果，不会改为提亮整个画面。定位不调用外部服务，不上传检测图像或保存人脸数据。

处理在老师浏览器的 WebGL GPU 着色器中完成：肤色范围内提亮和保留边缘的平滑处理。磨皮使用近、远两种范围的采样，滑杆提高时同时扩大处理范围并增加平滑强度，保留眼睛和亮暗轮廓边缘。老师本地预览、发给学生的 JPEG 和视频画中画使用同一处理结果；服务器继续负责权限校验和画面转发。GPU 不可用或上下文丢失时回退到原画并显示提示，不中断课堂或重启设备。

短暂连接中断只暂停传输、清除旧的接收画面，保留已开启的设备和桌面悬浮窗。重连后继续使用原来的设备，保留静音、关闭摄像头及分享／共享模式。普通站内页面切换由平台常驻通信层承载，不重新创建课堂媒体实例。

使用中的摄像头或麦克风被拔下、休眠后失效时，课堂会在设备重新可用且浏览器仍显示已授权时尝试恢复。学员和老师也可以通过各自的设备按钮手动重试。上课途中主动关闭的摄像头和主动静音的麦克风会保留原选择。

## 自动续课

首次点击上课成功后，服务器为该账号保存已参与课堂的恢复记录，它与短期设备连接租约分开保存。老师未下课时，刷新、关闭后重开、进入其他课堂或账号页面，都可以自动恢复原课堂。未点击过邀请的学员不会被自动加入。

恢复时重新校验账号、原课堂成员、工作区和登录权限。恢复接口按账号查找已参与的课堂，不接受页面或本地存储指定任意课程。连接持续采用退避重试，心跳未得到回应也会触发恢复；新页面接管后，旧页面停止自动恢复，避免来回抢占摄像头。

老师明确下课会结束整节课并清除双方的恢复记录；学员明确离开只停止自己的自动恢复。断网时点击下课或离开，会先在本地记住待同步操作，联网或再次进入平台后先提交该操作，期间不自动开启设备。

网络恢复后会重新准备分享／共享，短暂断线不当作结束连接。课堂内教师批注以同一课堂为范围保留，长期断线重新建立画面传输时仍可恢复本机批注。跨工作区页面的画面共享继续受原有页面权限约束。

## 权限与排课

课程仅一位老师与一名学员可见，接口重新校验登录、Token 权限、课堂成员及工作区。代登录不能使用。学生只能进入自己的课程，取消和结束整节课限授课老师。单个账号同一时刻只允许一个课堂媒体窗口。

预约按北京时间输入，接口保存带时区的时间。后端使用老师、学员各自的分钟预约锁，阻止同一时间重复安排；取消或结束后释放。计划时长默认 60 分钟，最长 240 分钟，可预约一年以内。正在进行的课堂不再按计划结束时间或连接租约过期而自动下课；未开始的过期预约仍按预约时间校验。

## 课堂中断时会发生什么

| 情况 | 老师和学员看到的结果 |
| --- | --- |
| 网络逐渐变慢，语音和视频争用带宽 | 摄像头自动降清晰度和帧率。积压的旧画面丢弃，网络恢复后直接显示近况。 |
| 一端还收得到画面，但上传方向已经中断 | 除了观察画面是否到达，客户端还检查往返心跳。失去回应后重新连接，保留课堂和已选设备状态。 |
| 双方同时掉线，或连续掉线几次 | 各端独立恢复原课堂。先前连接的画面、语音和授权消息不能接管新连接。 |
| 离开标签页、电脑睡眠、恢复时积压了媒体消息 | 回来后重新检查连接、设备和帧的有效时间，丢弃旧画面和过期语音。 |
| 麦克风或摄像头拔下、切换设备、浏览器撤销授权 | 只对之前确实在用且仍获授权的设备有限重试；需要手动操作时显示对应设备的指引。 |
| 学员拒绝麦克风、主动静音，或耳机输入中断 | 学员仍能听老师讲话。浏览器暂停播放时，课堂显示「点一下，听课堂声音」按钮，可单独恢复收听。 |
| 课堂过程中接到独立语音来电 | 响铃时课堂继续通话。一旦接通，课堂暂停收发声音，摄像头和屏幕继续工作。挂断后按原来的静音状态恢复。 |
| 屏幕授权被取消、停止，或下课后弹窗才返回 | 取消后仍可上课；已离开的课堂立即释放迟到的授权。重新观看只使用当前课堂仍有效的授权。 |
| 掉线期间老师下课或学员选择离开 | 先关闭本地设备；恢复网络时优先同步退出，防止设备被旧课堂重新开启。 |

## 什么时候需要升级服务器

一对一课堂的摄像头和屏幕由发送方浏览器编码，服务器转发给另一方。单个学员卡顿时，先核对同一时刻其他课堂的体验，以及该学员上行、收听设备和浏览器的情况。出现多间课堂同时卡顿时，比较同时上课数、服务器出入带宽、CPU 和内存曲线。出口持续用满时优先增加带宽；带宽有余量但 CPU 持续用满、消息转发也变慢时评估升配 CPU；出现持续换页或进程因内存不足退出时再评估内存。老师查看动态学员屏幕和只开摄像头的带宽需求不同，容量判断应包含这两种场景。

## 验证与发布

限速回归使用两个 Chromium 浏览器、虚拟摄像头和麦克风、本地 WebSocket 中继。可用以下命令把慢网时段延长到三分钟。测量范围从中继收到当前摄像头帧，到另一端浏览器解码并显示该帧。

```sh
LESSON_CAMERA_SLOW_MS=180000 node --test test/lesson_camera_latency.browser.spec.js
```

在装有 Playwright WebKit 和 Chrome 的 Mac 上，以下命令分别让老师、学员使用 WebKit，与 Chrome 交换摄像头画面和语音，并在断开连接后检查两端恢复。

```sh
LESSON_MAC_BROWSERS=1 HERO_CHROMIUM_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" node --test --test-name-pattern='macOS WebKit' test/lesson_camera_latency.browser.spec.js
```

行为测试还包括预约时区、到时提醒、显式加入、设备权限失败、晚到授权、画中画生命周期、分享切换及房间隔离。

```sh
node --test test/lesson_protocol.spec.js test/lesson_camera_flow.spec.js test/lesson_model.spec.js test/lesson_media.spec.js test/lesson_beauty.spec.js test/lesson_ui.spec.js test/lesson_broadcast.spec.js test/voice_call_audio.spec.js
node --test test/lesson_backend.spec.js test/lesson_ui.browser.spec.js test/lesson_media.browser.spec.js
```

后一组需要可启动的 MongoDB 和 Chromium。受限执行环境中无法启动数据库或浏览器时，不应将这些集成测试标为通过。

发布前在本地运行生产界面构建，并提交 `packages/ui-default/public/manifest.json` 及其引用的静态文件。生产服务器使用已有预构建发布脚本更新并重启服务。
