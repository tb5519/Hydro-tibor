# OneByOne Scratch 域

Scratch 作为 Hydro 内置模块运行，使用同一个网站、账号、域成员和文件存储，不需要 Flask、第二个 Web 服务或新域名。

## 使用

1. 登录后进入「我的域 → 创建域」，选择「Scratch 创作域」。工作区内创建域也有同样选项。
2. 域管理员从「学员管理」管理成员，发布作业、上传起始 `.sb3` 项目和课堂素材。
3. 学生进入该域后直接打开 Scratch 课堂，可以自由创作、从素材开始，或完成作业。
4. 编辑器上方「保存作品」保存草稿；作业作品可「提交作业」。老师打开提交快照后填写评价和反馈。

Scratch 顶部菜单统一提供首页、作品、作业和素材，老师还能进入发布作业与学员管理。首页「开始创作」与作品页右上角「新建作品」都会先弹窗填写名称。作品卡使用完整舞台截图，左上角显示名称铭牌，左下角并排放播放、编辑按钮。播放直接打开大舞台并运行绿旗，编辑进入原生文件／编辑／名称菜单；右侧保留 OneByOne 保存与作业提交。原生菜单修改作品名称后，需要保存才会同步到作品列表。

作品卡右上角的分享箭头生成文字与免登录播放链接。作者或本域老师可以分享已保存作品，链接固定指向当时的版本，后续编辑不会改变它。分享窗口可关闭该作品的全部分享；再次分享会生成新链接。没有保存的作品会提示先保存。公开页面只包含作品标题与该快照，不展示课堂、学生或提交数据；课堂及普通文件接口仍要求登录与域权限。

老师身份沿用域的「编辑域」权限。学生只能编辑自己的作品；老师可以查看本域作品、批改提交，不能覆盖学生的项目。指定成员可见的素材只能被接收成员和老师读取。

作品页可下载 `.sb3`、上传已有项目、恢复历史版本。恢复会生成新版本。已提交的快照独立保留，之后修改草稿不会覆盖它。

## 与现有题库的关系

现有域没有 `domainType` 字段时仍按 OJ 处理，不需要迁移题库。新建域默认仍为 OJ，域类型创建后固定。Scratch 使用独立的 `scratch.*` 集合和文件命名空间，不写入 OJ 的题目、提交记录或评测队列。

Scratch 域从 RP 计算和全域排行榜数据源中排除，域内不展示 OJ 排行榜与荣誉墙。同一个账号在普通 OJ 域的成绩仍按原规则参与排名。

原 Flask 项目目录保持原样。原平台账号、作品和素材没有自动导入；已有 `.sb3` 可直接上传到新平台。

## 小服务器上的资源控制

- 播放、编辑和缺失封面的补生成使用独立 Scratch/TurboWarp 前端；项目在学生浏览器执行，服务器无需新增渲染服务。
- 已有封面按普通图片懒加载。旧作品缺图时，仅对可见卡片使用一个隔离实例依次截图，不运行积木；作者的截图缓存不创建作品版本、不改变更新时间。未保存的作业仍跟随老师的起始项目，封面只临时展示；保存及恢复版本时更新或清除旧封面。
- 带内容哈希的编辑器脚本缓存一年，页面入口重新验证；现有 Hydro 响应压缩继续生效。
- 单文件最多 20 MB；每人每域最多 200 个作品；保留最近 10 个草稿版本，每个作品最多 50 次作业提交；每域 Scratch 文件配额 2 GiB。
- 正在分享的快照在历史草稿清理时继续保留并计入原有文件配额；关闭分享后，没有其他引用的旧快照才可清理。删除作品或域会使对应分享失效。
- 原生存储的延迟删除仍适用，清理的文件不一定立刻释放磁盘空间；备份需同时覆盖 MongoDB 和 Hydro 文件存储。
- 初次加载编辑器需要下载资源，1 Mbps 带宽下应允许较长等待；学生各自浏览器缓存后能减少重复下载。

编辑器和默认项目由本地资源提供。上游内置角色、造型和声音库在选取部分素材时会请求 Scratch 公共素材服务；课堂需要的素材可以上传 `.sb3` 或文件预先准备。自定义 JavaScript 扩展禁用，当前开放画笔、音乐和 Makey Makey。

## 本地构建与验证

独立编辑器的固定上游版本、可重现构建命令与许可证说明见 [build/scratch/README.md](build/scratch/README.md)。

```sh
node build/scratch/build.mjs
node build/scratch/verify.mjs
yarn build:ui:production
node -r @hydrooj/register --test test/scratch_backend.spec.js test/scratch_domain_integration.spec.js test/scratch_home_ui.spec.js test/scratch_inner_editor.spec.js test/scratch_thumbnails_ui.spec.js test/scratch_share_ui.spec.js test/contest_timer.spec.js test/ui_static_asset_reload.spec.js
```

后端测试启动临时 MongoDB，不使用生产数据。主 UI 构建保留 `public/scratch-editor`；最终发布必须包含本地生成的 `packages/ui-default/public/manifest.json`、所有引用的哈希文件及独立编辑器产物。

生产服务器严禁构建 UI 或 Docker 镜像。用户本地验收确认后才能 push；生产仅拉取已准备的提交、重启 Hydro、等待健康检查通过，再重启 Judge。此次实现尚未 push 或部署。
